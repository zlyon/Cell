# Cell（无限服分支）

Cell 团队框架的分支版本，针对「无限服」客户端（基于正式服 12.1.3 客户端，版本 1.60.1，Interface 16001）做了修复与适配。

上游血缘：`enderneko/Cell` → `NeeRgY/Cell`（r277.9.9.3）。本仓库在其基础上继续修改，版本号沿用 `r277.9.9.x-forever` 的形式。

## 本版改了什么

- **专精识别**：无限服没有传统专精页，只有一棵天赋树。改为依据天赋树各列已投入的点数推导真实专精（九个职业 × 三个专精），并监听天赋变更自动刷新；修复切换专精时布局索引为空的报错。「点击施法 → 为每个专精使用独立配置」不再显示「无专精」。
- **点击施法预设**：不再写死正式服法术 ID，改为合并该职业全部专精的法术表 + 扫描角色法术书；剔除基础攻击、只能对自己释放的技能、纯伤害技能（既能打敌人又能治疗友方的双向技能保留）。
- **旧配置迁移**：内置一次性迁移，读取 URF Forever 的按键绑定，转换成 Cell 的点击施法格式并补齐（只补缺失键位，不覆盖已有配置）。
- **中文化**：补上「副本减益」页说明的中文分支，翻译光环黑名单小部件的表头与提示，重写更新说明。
- **关于页**：更新链接与致谢，整理入口按钮。

## 安装

1. 下载 Release 里的 zip，解压得到 `Cell` 文件夹。
2. 丢进 `World of Warcraft/_forever_/Interface/AddOns/`。
3. 进游戏，`/reload`。

插件目录里同时存在多个 toc，由客户端按自身版本号挑选，**不要**把 `Forever` 拆成独立插件。

## 已知限制

- 无限服对小队/团队框体上的大量战斗光环启用了「保密值」（secret values）：能照常绘制，但插件读不出内容。凡是要「先读光环再判断」的功能都失效了，例如自定义副本减益列表、控制技能列表、光环黑名单、缺少增益判断、施法目标高亮。
- 布局、指示器、外观无法从旧版本自动迁移，需要重新配置一次。
- 由于上述限制，任何依赖真实数值的比例/百分比显示都做不了。
